# Backend Analysis Report

## Overview
The backend is a **Node.js** application built with **Express** and **Socket.IO**. It follows a modular structure:

- **config/** – Database, Redis, and other environment configuration.
- **middleware/** – Request validation, authentication, and error handling.
- **routes/** – RESTful endpoints for businesses, products, sales, expenses, debts, dashboard, payments, admin, and support.
- **services/** – Business logic, often interacting with the database via Knex.
- **workers/** – Background jobs (stats, inventory, finance) scheduled with cron‑like intervals.
- **jobs/** – Job definitions used by the workers.
- **scripts/** – Utility scripts for migrations, backups, and diagnostics.
